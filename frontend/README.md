# Frontend for WatchOS-26 Chatbot

This is the frontend application for the WatchOS-26 Chatbot. It provides the user interface and handles interactions with the backend services.

## Features
- User-friendly interface for interacting with the chatbot.
- Integration with backend APIs for seamless communication.
- Lightweight and efficient design.

## Prerequisites
- Python 3.12 or higher
- pip (Python package manager)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/shubhamagr24/watchos-26-chatbot.git
   ```

2. Navigate to the frontend directory:
   ```bash
   cd watchos-26-chatbot/frontend
   ```

3. Create and activate a virtual environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

4. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Run the application:
   ```bash
   streamlit run app.py
   ```

2. Open your browser and navigate to the provided URL (e.g., `http://localhost:8501`).

## File Structure
- `app.py`: Main Streamlit application entry point.
- `requirements.txt`: Project dependencies.
- `.env.example`: Template for environment variables.
