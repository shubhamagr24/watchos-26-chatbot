# Deployment Instructions

## Frontend Deployment
The frontend of the application was deployed to **Streamlit Cloud**. Ensure that the backend URL is updated as an environment variable in the frontend application to enable proper communication between the frontend and backend services.

## Backend Deployment
The backend of the application was deployed to **Render Service**. All required environment variables were configured in the backend to ensure the application runs smoothly. These environment variables include any necessary API keys, database URLs, or other configurations required by the backend services.
